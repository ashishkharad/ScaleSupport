[SYSTEM OVERVIEW & PURPOSE]
Build a comprehensive, enterprise-grade, full-stack Stressed Asset Recovery Management System (SRMS) branded as "ScaleSupport". The platform digitizes, automates, and accelerates non-performing asset (NPA) and loan collection workflows for banks, NBFCs, collection agencies, and recovery agents. It features a responsive Web Recovery Coordinator Portal and an Android Mobile Field Recovery Application, backed by real-time Google Sheets database synchronization (19 structured sheets), Google Drive cloud evidence storage, AI recovery intelligence, offline-ready field collection tools, and multi-account borrower reconciliation.

5. CORE SPECIALIZED ENGINES & WORKFLOWS
--------------------------------------------------------------------------------

1. EXCEL IMPORT & DYNAMIC ALLOCATION ENGINE:
- Supports banking standard raw export files (CSV, XLS, XLSX).
- Automatically maps 9 core bank columns + flexible aliases:
  * BR_CD (Branch Code)
  * BR_NAME (Branch Name)
  * AC_NO (Account Number)
  * AC_NAME (Customer / Borrower Name)
  * PROD_DESC (Product Description e.g., KCC, LAP, HL, AL, PL, TW)
  * FACILITY (Facility Type)
  * SANC_LIM (Sanction Limit)
  * LOAN_B (Loan Balance / Overdue Balance)
  * NPA_DT (Date of NPA Classification)
- Performs automatic type coercion, currency sanitization, deduplication, and bulk agent assignment.

2. MULTIPLE ACCOUNT MATCHING & CONSOLIDATED BORROWER SINGLE VIEW:
- Automatic detection of borrowers holding multiple credit facilities across branches.
- Matching heuristics: Identical Customer ID / CIF, or identical Contact Phone, or matching Loan Balance + NPA Date combination.
- "Single View" Customer Modal (`CustomerConsolidatedDetailModal.tsx`):
  * Displays complete 360° Borrower Profile (Total Pool Overdue, Active/Broken Status, Sanctioned Credit).
  * Linked Accounts Table with breakdown of individual loans, facilities, and branch codes.
  * Direct action buttons to Log PTP across accounts, Collect Consolidated Recovery, Attach Notes, Upload Docs, or Trigger AI Settlement Strategy.

3. AGENT NOTES MANAGEMENT ENGINE:
- Quick "+ Note" modal and inline inputs across all accounts and timeline views.
- Categorized notes: 'PTP Commitment', 'Field Visit', 'Dispute', 'Address Verification', 'Follow Up', 'Payment Collection'.
- Persistent logging attached to account records and synced to Google Sheets Tab 4 & Tab 6.

4. PTP DIGEST & GOOGLE SHEETS BATCH AUTO-RESOLVER:
- Interactive "⚡ PTP Digest" notification button on the Dashboard and PTP management hub.
- Compares all 'Pending' PTP commitments against the current reference date.
- Identifies expired promises (promised date < current date).
- 1-Click Batch Execution:
  * Transitions expired commitments from 'Pending' to 'Broken'.
  * Updates the corresponding Account status to 'PTP Broken'.
  * Generates high-priority coordinator notifications and system audit logs.
  * Synchronizes all 19 Google Sheets database tabs in a single batch request.
  * Provides detailed metrics: Total Evaluated, Expired Broken, Due Today (Actionable), Upcoming, and Achieved.
  * Features a copyable executive summary report.

5. 19-TAB GOOGLE SHEETS DATABASE ARCHITECTURE:
Full structured synchronization with Google Sheets encompassing 19 dedicated tabs:
  - Sheet 1: Users (User ID, Name, Role, Branch, Agent ID, Mobile, Status)
  - Sheet 2: Agents (Agent ID, Name, Branch, Area, Monthly Target, Status)
  - Sheet 3: Customers (Account ID, Customer Name, Mobile, Address, City, Category)
  - Sheet 4: Accounts (Branch, Account ID, Product, Sanction, Balance, NPA Date, PTP Count, Status)
  - Sheet 5: Allocations (Allocation ID, Account ID, Agent ID, Date, Priority, Status)
  - Sheet 6: FollowUps (FollowUp ID, Account ID, Agent ID, Date, Contact Mode, Disposition, Next Date)
  - Sheet 7: PTP (PTP ID, Account ID, Customer Name, Agent ID, Amount, PTP Date, Mode, Status)
  - Sheet 8: Recoveries (Recovery ID, Account ID, Amount, Mode, Receipt No, Txn Ref, Date, Status)
  - Sheet 9: FieldVisits (Visit ID, Account ID, Agent ID, Date, Visit Type, Met, GPS Coordinates, Outcome)
  - Sheet 10: GeoPhotos (Photo ID, Account ID, Photo Type, GPS Lat/Lng, Timestamp, Storage URL)
  - Sheet 11: VoiceNotes (Voice ID, Account ID, Agent ID, Duration, Date, Audio URL, Transcript)
  - Sheet 12: Documents (Doc ID, Account ID, Doc Type, Upload Date, Verified, File URL)
  - Sheet 13: ActivityLogs (Log ID, Timestamp, User ID, Role, Action Type, Details)
  - Sheet 14: Notifications (Notif ID, Timestamp, Recipient, Title, Type, Read Status)
  - Sheet 15: AgentCommissions (Commission ID, Agent ID, Recovery ID, Amount, Rate, Incentive, Status)
  - Sheet 16: Branches (Branch Code, Branch Name, Area, Zone, Manager Name, Total Accounts)
  - Sheet 17: Areas (Area Code, Area Name, Zone, Regional Head, Total Branches)
  - Sheet 18: Zones (Zone Code, Zone Name, Zonal Head, Total Areas)
  - Sheet 19: CommissionSettings (Slab Name, Min Amount, Max Amount, Base Rate %, Bonus %)

6. GOOGLE DRIVE CLOUD HIERARCHY STORAGE:
- Automatic folder structure: `/ScaleSupport_SRMS / [Zone] / [Branch] / [Account_ID - Customer_Name] /`
- Sub-folders organized into `Geo_Photos/`, `Voice_Notes/`, `Payment_Receipts/`, and `Legal_Documents/`.
- File metadata tagging and direct preview links.

7. WATERMARK CAMERA & GEO-VERIFICATION:
- HTML5 Canvas & Geolocation API engine.
- Captures live camera stream and burns indelible metadata directly onto the image:
  * ScaleSupport Verified Recovery Watermark
  * Account Number & Borrower Name
  * Recovery Agent ID & Agent Name
  * Precise GPS Latitude, Longitude, and Altitude
  * Date and Time Stamp (IST / Local time)
  * Digital Hash for tamper prevention

8. VOICE NOTE AUDIO RECORDER:
- Web Audio API / MediaRecorder implementation.
- Real-time sound wave visualization, pause/resume, playback scrubber.
- Generates base64 / audio blob with local fallback and cloud sync.

9. AI RECOVERY INTELLIGENCE DRAWER:
- Integration with Gemini API / AI reasoning engine.
- Generates tailored recovery strategies based on:
  * Days past due (DPD) & NPA Age
  * Loan balance & asset category
  * Previous PTP breach history & customer sentiment
  * Suggested settlement discount concessions (OTS - One Time Settlement)
  * Legal escalation recommendations (SARFAESI, Section 138, Lok Adalat, DRT).
